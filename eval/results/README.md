# Full-run results

This directory is reserved for final benchmark analyses keyed by an analysis
label:

```text
eval/results/{analysis_label}/
```

Typical outputs include model metrics, per-subtype statistics, SDT-IRT fits,
cost summaries, and figures. Standard full-run workflows write here; VLM
design-choice study outputs remain isolated under
`eval/design_choices/artifacts/results/`.
